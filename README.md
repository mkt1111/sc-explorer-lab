# SC Explorer Lab

An interactive introduction to stochastic computing: representing numbers as random bit streams and computing with simple logic gates.

## Features

- Modules: Introduction, Bit Streams, Operations, Simulator
- Bit-stream and probability visualizers
- Comparison of traditional vs. stochastic multiplication (AND gate)
- Interactive multiplication simulator with adjustable stream length

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui (Radix UI)
- React Router
- TanStack Query
- lucide-react

## Running locally

Requires Node.js and npm.

```sh
npm install
npm run dev
```
